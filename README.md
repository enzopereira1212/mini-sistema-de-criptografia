# Mini Cofre em Python

Projeto desenvolvido para estudo de criptografia de arquivos usando Python e a biblioteca `cryptography`.

## Funcionalidades

- Criptografar arquivos
- Mover arquivos para pasta segura (vault)
- Descriptografar mediante chave correta
- Validação básica de segurança

## Tecnologias utilizadas

- Python 3
- cryptography (Fernet)

## Objetivo

Projeto criado com foco em aprendizado de:
- Manipulação de arquivos
- Organização de projetos
- Criptografia básica
- Validação e fluxo lógico
